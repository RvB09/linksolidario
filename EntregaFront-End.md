Entrega do Front-End - Seminario Integrador

1. tntroducão
O presente documento refere-se a entrega do front-end do projeto desenvolvido pelo grupo "Link Solidário" no contexto do Seminario Integrador. O objetivo principalk é apresentar as telas implementadas, a estrutura do respositório e a contribuição de cada integrante, conforme os requisitos definidos pela atividade.

2 Tecnologias Uilizadas
- HTML5
- CSS3
- JavaScript
- Frameworks: Bootstrap (para responsividade)
- Feramentas: VS Code, Git, GitHub

3. Telas Implementadas
Foram implementadas as seguintes telas no front-end:

- Tela de Login: Formulário com campos de e-mail e senha.
- Tela de Cadastro: Inclusão de nome, e-malil, senha e tipo de usuário.
- Tela de Listagem de Produtos: Exibe os produtos cadastrados com nome, descrição e botão de ação.
- Tela de Busca: Permite filtrar produtos por nome ou categoria.
